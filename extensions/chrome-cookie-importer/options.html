Envio de logs para a API

A extensão pode enviar logs estruturados para diagnóstico remoto. Cole a API key configurada no servidor (env EXTENSION_LOGS_API_KEY). Se vazia, o envio fica desativado. Gere uma com openssl rand -hex 32.
