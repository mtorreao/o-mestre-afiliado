# e2e/fixtures/

Evidências visuais e artefatos estáticos de testes E2E. Imagens anexadas a
issues / PRs para documentar regressões visuais e estado da UI validado.

## Subpastas

- `evidence/` — capturas usadas como prova visual de correções (a11y, layout, etc.).

## Política

Os arquivos aqui são versionados quando representam **uma correção** documentada
na mensagem do commit. Artefatos de execução do Playwright (`screenshots/` na
raiz de `e2e/`) ficam no `.gitignore`.
